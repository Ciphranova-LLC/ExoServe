Security and Authentication

Session TTL

Maximum time in seconds that an inactive login session is valid.

File System Lock TTL

Maximum time in seconds that a lock on the file system is valid.

Nonce TTL

Maximum time in seconds that a login challenge from the server is valid. Note that challenges are immediately invalidated once completed.

Storage and Performance

Concurrent Search Workers

Maximum number of concurrent network connections during a search job. A higher number has the potential to search more quickly, but requires more network bandwidth.

File Chunk Size

Size of chunks in MB when streaming file uploads and downloads.

Trashed Files

Maximum number of days that files will stay in trash before being permanently deleted automatically.
