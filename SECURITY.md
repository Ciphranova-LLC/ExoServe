| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please report it privately using one of the following methods:

1. **GitHub:** Navigate to the **Security** tab of this repository, select **Advisories**, and click **Report a vulnerability**.
2. **Email:** Send an email directly to [security@ciphranova.com].

Please include a brief description of the vulnerability and steps to reproduce it. All reports are taken seriously and will be acknowledged as quickly as possible.
