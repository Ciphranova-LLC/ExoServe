## Features
- **Client-side encryption** of all file contents, file names, folder names, and directory structure
- **Upload** and **download** any file from any device with a web browser.
- **Batch upload** folders
- **Drag and drop** to upload
- **Rename** uploads
- **Preview** photos, videos, audio, PDFs, and text files in browser
- **Procedural decryption** to preview large files during decryption
- **Multi-user** and **concurrent session** support
- **Configurable settings** for the server and individual users
- **Trash** folder
- **Search** uploads by name
- **Sort** folder view by name, date, or size
